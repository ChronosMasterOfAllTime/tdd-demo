## TDD/Github Action Demo Repo

The purpose of this repository is to demo different capabilities of TDD/GHAs across multiple modern technology stacks.

### Technology Stacks (All Updated to Latest Versions)

This repository includes examples and demonstrations for:
- **Vue 3** (v3.5.21) with TypeScript, Vite 6, Vitest 2, Tailwind CSS 3, and Pinia 3
- **Node.js** (v22+ LTS) with TypeScript 5, Jest 29, ESLint 8, and modern Babel
- **Go** (v1.25) with modern testing and coverage
- **Java** (v23) with Gradle 8, Spock framework for testing
- **.NET** (v8 LTS) with MSTest and comprehensive coverage
- **Python** (v3.13) with pytest 8 and pylint 3

### GitHub Actions Demos
- Release Drafter
- PR Checks with multi-language validation
- Release Publisher
- Automated testing across all technology stacks
- Modern CI/CD pipeline with latest action versions
